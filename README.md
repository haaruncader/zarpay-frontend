# ZarPay – Frontend

ZarPay Frontend is a React application that provides a simple user interface for interacting with the ZarPay digital wallet backend.
It allows users to view their wallet balance, review transaction history, deposit funds, and transfer money between users.

---

**Features**
- Wallet dashboard
- Display ZAR balance
- Ledger-style transaction history
- “See all” transaction history
- Deposit money
- Transfer money to other users

---

**Screens**
- Wallet Dashboard
- Deposit Screen
- Transfer Screen

---

## 🛠 Tech Stack
- React
- JavaScript
- Axios
- HTML & CSS

---

**Backend**
This frontend connects to the ZarPay Spring Boot backend:
https://github.com/haaruncader/ZarPay

---

▶️ Run Locally

**Prerequisites**
- Node.js (v18+ recommended)
- npm

**Start the app**
npm install
npm start

📌 Notes
Communicates with backend via REST APIs using Axios
State managed using React hooks
Authentication currently email-based (JWT planned)
UI intentionally kept simple and functional
